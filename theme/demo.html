Galeria de demonstração

Clique em uma foto para abrir o visualizador. Use ← → para navegar e Esc para fechar.

Tema de interface para ViewerJS. Nenhum recurso original é removido: zoom, rotação, espelhamento, slideshow, navegação, miniaturas, tela cheia, teclado e gestos continuam ativos. Os botões de modo acima recriam o visualizador com variações para comparação.
