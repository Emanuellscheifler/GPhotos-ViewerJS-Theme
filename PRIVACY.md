# Privacy policy

This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

## Dados tratados pelo aplicativo

- O aplicativo lê apenas as imagens das pastas e dos arquivos que o usuário abre
  explicitamente.
- Nenhuma foto, nome de arquivo, caminho ou metadado é enviado para servidores.
- Não há telemetria, analytics, contas, anúncios ou atualização automática.
- A única preferência salva localmente é o tamanho/posição da janela, em
  `%APPDATA%\Visualizador de Fotos\settings.json`.

## Serviços de terceiros

- O instalador é distribuído pelo GitHub Releases. O GitHub pode registrar estatísticas
  de download conforme a política de privacidade do GitHub.
- As imagens de demonstração do repositório vêm do Lorem Picsum/Unsplash e não fazem
  parte do aplicativo instalado.
